# 高麗藏 ⇄ 大正藏
## 位置轉換表

**把「翻書找對應位置」變成「一行指令」**

涵蓋 1,474 部經、6,357 卷、4,590 萬漢字

---

## 一、要解決的問題

研究上經常需要指著一邊藏經的某一行，問「另一邊在哪裡」。

例如：

> 大正藏 T01p0005b05 第 3 字，
> 在高麗藏是 **K17p0819b17 第 8 字**

這種對照，過去只能一卷一卷翻、一段一段找。

**問題不是「找不到」，而是「做不完」**——全藏有 344 萬行（高麗藏）對 690 萬行（大正藏）。

---

## 二、為什麼這件事特別難

| 難處 | 具體情況 |
|---|---|
| **分卷不同** | 同一段文字，兩藏的卷號可能不一樣；有的經在《大正藏》分十卷、《高麗藏》只有五卷 |
| **行數不同** | 卷與卷之間空幾行、空半頁是常態；兩邊對「第幾行」的認定會差一兩行 |
| **用字不同** | 同一字兩邊字形不同：說／説、為／爲、眾／衆、緣／縁… |
| **有增有減** | 一邊有的句子，另一邊沒有；序文、附文、校勘註的處理也不同 |

靠人工比對，這四件事會同時發生，所以很容易錯。

---

## 三、本方案的特點

**① 逐字對齊，不是整卷粗略對應**

轉換結果精確到**某一行、第幾個字**，不是只說「大概在這一卷」。

**② 對應關係只有 1.54 MB**

「哪個字對哪個字」壓縮成單一檔案，**完全離線可用**，不必連 CBETA、也不必連東國大學。
這 1.5 MB **只裝對應關係，不裝經文**——經文仍來自原有的兩份資料庫。

**③ 會告訴你「這裡沒有對應」**

遇到序文、附文、或一邊多出一段時，程式會**標明這不是一對一對應**，而不是硬給一個位置。

**④ 兩邊都能查**

大正藏 → 高麗藏、高麗藏 → 大正藏，雙向都能轉。

**⑤ 帶著走**

整份對照表能放進**一個網頁檔**——**手機開得動**、離線可跑，帶去**圖書館**查也不必連線。

---

## 四、它涵蓋了什麼

| 項目 | 數量 |
|---|---|
| 高麗藏 | 45 冊、**344 萬行**、6,594 卷 |
| 大正藏 | 85 冊、**690 萬行**、11,995 卷 |
| **可互相對照** | **1,474 部經、6,357 卷、4,590 萬漢字** |
| 對照檔大小 | **1.54 MB**（未壓縮 12.55 MB）——**只含對應關係，不含經文** |
| 經文本身（另存） | 高麗藏 373 MB ＋ 大正藏 771 MB |

作法是：把兩藏的同一卷文字，用「最長共同子序列」逐字排好，記下每一段的對應關係。

壓縮方式**借鏡軟體界的 source map**——不重存經文，只記「哪一段對哪一段」。同一卷通常因此收斂到個位數段，全藏壓到 **1.54 MB**，**極致的小容量**。

---

## 五、測試結果

**抽樣 1,949 個位置，涵蓋 1,474 部經**（每一部經最多取 2 點，完全分散、不集中在少數幾部）

| | |
|---|---|
| **通過** | **1,941 / 1,949 ＝ 99.59%** |
| 回程一致（轉過去再轉回來） | 1,944 / 1,949 |

**驗證方式**：不是拿程式自己的紀錄來對，而是**轉換之後直接回到兩邊的資料庫，把那個位置上的正文調出來比對**——確認兩邊真的是同一段文字。

**失敗的 8 例中，有 5 例是《高麗藏》本身在該處就不同或缺頁**（例如《釋迦譜》十卷本與五卷本之別），不是轉換錯誤。

## 六、速度，以及和翻書相比

**程式本身的速度**

| 動作 | 時間 |
|---|---|
| **查一個位置**（含程式啟動） | **0.027 秒** |
| 連續批次轉換 | **843 個位置／秒** |
| 建立全藏完整對照表（6,357 卷） | **121 秒** |
| 載入對照檔（解壓＋校驗） | 0.32 秒 |

**與人工翻書對照**——以熟悉文本的研究者、每個位置約 **2–5 分鐘**估計：

| 工作量 | 翻書 | 本程式 | 節省 |
|---|---|---|---|
| 1 個位置 | 2–5 分鐘 | 0.03 秒 | — |
| 100 個位置 | 3–8 小時 | 0.1 秒 | 約 **10 萬倍** |
| 1,000 個位置 | **4–10 個工作日** | **1.2 秒** | — |
| 全藏 6,357 卷的完整對照表 | **無法完成** | **121 秒** | — |

**真正的差別不是快，而是「本來做不到的事現在做得到」**——全藏規模的逐字對照，人工沒有可行性。

---

## 七、該注意的限制

- **版本差異處不會無中生有**：若一邊本來就沒有那段文字，程式會標示而非編造。
- **字形差異仍在**：說／説這類異體字，是兩套電子文本各自的編碼習慣，引用時宜註明版本。
- **少數疑難卷**：全藏中有數十卷因分卷方式不同（例如《大正藏》十卷本對《高麗藏》五卷本），對照僅供參考。
- **它替代的是「找位置」，不是「讀懂」**。

---

## 八、怎麼使用

**查一個位置**

```
poscli convert T01p0005b0503
→ 高麗藏 K17p0819b1708（精確對應）
```

**批次處理**：把一批位置交給程式，一次跑完，輸出成表格。

**主要產出物**

| 檔案 | 用途 |
|---|---|
| `poscli.exe` | 單一執行檔，內含轉換演算法 |
| `posmap.pos` | 1.5 MB 對照資料 |
| `postest-cases.tsv` | 1,949 筆測試明細，可自行核對 |

**完全離線**，不依賴任何線上資料庫。

本表的建置與除錯，感謝 **DeepSeek Harness** 協助，省下大量人工排查與建表的時間。
