# 從大正藏解耦：高麗藏與大正藏的位置對照（工程報告初稿）

> 給文獻學同行的初稿。格式從簡、未附完整徵引，請直接批註。

## 一、問題

今天漢文佛學研究的引用，幾乎都以《大正新脩大藏經》的頁、欄、行為座標。這套座標之所以能壟斷，不完全因為它校勘最精，而是因為它最早完成、收錄最全、版面最便查，於是引用的**替換成本**最高。

問題出在下一步：一旦要認真校勘，就必須翻其他版本。而翻查的動作——由大正藏某一行找到高麗藏對應的那一行——目前完全是人工的。一部經數十卷，逐處核對，時間成本高到讓多數研究卻步。**這個成本，才是既有標準真正的護城河。**

因此本工作的目標不是編一套更好的藏經，而是**把位置從單一版本的版面解耦**：給定一個大正藏位置，立刻給出對應的高麗藏位置，精確到字。

## 二、這不是什麼

- 不做校勘判斷，不產生校勘記，不判斷兩版本孰是孰非。它只做座標轉換。
- 不主張高麗藏優於大正藏。目標是讓「多版本並用」成為預設，而不是換一個霸權。
- 不重編藏經。輸出是一張位置對照表，不取代任何現行版本。

一句話：**對齊不是目的；節省學者翻查版本的時間、讓引用不再綁死於單一版面，才是目的。**

使用時，學者仍然照舊引用大正藏。需要覆核時，把引用的位址貼進去，立刻得到高麗藏的位置，再去查對應的刻本圖版或文本。**引用習慣不必改變，改變的只是覆核的成本。**校勘工作的重心，也就從「找對應」移到「讀差異」。

## 三、底本

- **大正藏**：東京大學 SAT 資料庫 2018 年版。85 冊、6,901,609 行、11,995 卷。
- **高麗藏**：韓國東國大學的高麗大藏經數位文本。45 冊、3,413,757 行、6,596 卷（缺第 42、43 冊）。

兩邊都直接取自日、韓的母本，未經 CBETA 等既有衍生文本轉手。這樣做有兩個好處：對照結果不與任何單一衍生本互相污染，且這份對照可以獨立於任何既存電子藏經而被檢驗。

對照範圍限於「一對一且卷數相同」的經典：**1475 部、6360 卷**。其餘卷數不一、合刊、局部對應與無對照者共 27 部，尚未納入。

## 四、位置的寫法

沿用行業慣例：

```
T01p0002c0405   大正藏 第 1 冊 第 0002 頁 c 欄 第 04 行 第 05 個字之前
K17p0815a0301   高麗藏 第 17 冊 第 0815 頁 a 欄 第 03 行 第 01 個字之前
```

「第 N 個字之前」是字串指標：0 在「如」左邊，1 在「如」右邊（即「是」左邊）。

**偏置只數 CJK 表意字符**。標點、段落標記、異體字選擇符（IVS）都不計。理由是：兩藏的標點與標記系統本來不同（高麗藏用 `^p` 之類的標記，大正藏用新式標點），若把它們算進位置，兩邊座標立刻對不上，而且會製造大量假差異。

一個小擴充：偏置超過 99 的長行寫成 `T49p0024a17.118`。全庫只有 6 行超過 99 字，都在大正藏第 49 冊的表格類頁面，高麗藏 0 行。

## 五、對照怎麼做

兩藏的差異只有三種：刪、增、替代。

關鍵在**替代**。兩藏的正文差異絕大多數是異體字——大正藏作「説」，高麗藏作「說」；大正藏作「縁」，高麗藏作「緣」。這些不是內容差異，是**書寫系統的差異**。

一般的最短編輯脚本會把「説→說」記成一刪一增，於是每一個異體字都把位置圖切斷一次。一卷若有四百個異體字，位置圖就碎成數百段，而且每個異體字所在位置都會變成「無精確對應」。

我們的做法是：**把變動區塊裡的刪與增，按位置配對成「替代」**。異體字因此成為一對一的對應，位置圖得以連續。

配對之後，整卷化為一連串**一對一的對應段**。段內滿足 `k = t + 常數`——在一段之內兩邊等速前進，位置可直接平移；段與段之間才是單邊多出來的字（一方有、一方無）。

再一步：純替代不改變這個常數，所以**首尾相接、常數相同的段可以合併成一段**，查詢結果一字不差。效果顯著——《長阿含經》第一卷從 801 段降到 9 段。只有真正有插入或刪除之處才留下段界。

因此一卷只需存兩樣：對應段（起點與長度），以及每一行的行號與該行漢字數。後者讓「第幾個字」能還原成「第幾頁第幾欄第幾行第幾個字」。

這個結構與程式界的 source map 同構，但用途相反：source map 把編譯後的位置映射回原始碼，這裡把一個版本的版面映射到另一個版本。

**一個例子。** 輸入 `T01p0002c0405`，即《長阿含經》卷一第 2 頁 c 欄第 4 行第 5 個字之前。該行大正藏原文作「遍見無所畏　三會弟子衆」，偏置 5 落在「三」的左邊（全形空格不計）。換算得到 `K17p0816b1300`，高麗藏第 17 冊第 816 頁 b 欄第 13 行第 0 個字之前——該行行首也是「三」。兩邊對到的是同一個字。

## 六、序文與附文

有一類差異必須特別處理。

卷首的序常常只在一邊。例如《長阿含經》卷一，大正藏卷首有僧肇序 541 字，高麗藏沒有。卷末同理：刊記、題記、譯場記錄，也常只在一邊。

若不處理，這些字的「對應位置」會落到對方的別處，位置就錯了；而且它們本來就不該有對應——那不是同一段文字。

判準是：卷首或卷末那一段，**長度達 100 字以上，且區內兩藏完全相同的字數不到一半**，才算真正的單邊序文或附文。否則（例如兩藏都有的卷末經題，只是異體字之差）仍留在對照範圍內，照樣能對照。

另有兩種情形會明確回報：輸入落在整行沒有漢字的行（指針移到最近的有字行）；該頁欄行不在資料中。

## 七、體積與形態

全藏的對照資料：未壓縮 **13.13 MB**，zstd 壓縮後 **1.61 MB**——約為經文本身（157.5 MB，UTF-8，含標點標記）的 **1%**。

三種形態：SQLite 資料庫 19.7 MB；單一 binary 檔 1.61 MB；網頁用 JSON 1475 檔 17.5 MB。另有一個單一執行檔（9.8 MB，資料內嵌其中），啟動到可查詢約 74 毫秒，可離線使用。

## 八、驗證做了什麼、沒做什麼

**做了**（皆為內部一致性）：

- 逐字掃過 **45,829,948** 個可對照位置，檢查對照是否單調、是否落在正文範圍、來回轉換是否回到原點。
- 三條彼此獨立的實作路徑（TypeScript＋SQLite、瀏覽器版、Go 內嵌版）互相比對，共 4583 萬、1484 萬、397 萬次位置，逐欄一致。
- 與另一支獨立撰寫的相似度計算程式逐卷對帳，6360 卷的新增、刪除、替代三個數字完全吻合。

**沒做**：沒有外部標準。以上只證明系統自洽，**不能證明「對得對」**。位置對照正確與否，最終要由文獻學者核對原書。這是本次請各位審閱的主要目的。

## 九、初步發現

對照過程出現一些副產品，尚待系統整理，先列出供各位判斷輕重。

**用字差異**（箭頭為「大正藏→高麗藏」，全藏次數）：

| 大正藏 | 高麗藏 | 次數 | | 大正藏 | 高麗藏 | 次數 |
|---|---|---|---|---|---|---|
| 説 | 說 | 297,542 | | 陀 | 陁 | 59,127 |
| 縁 | 緣 | 132,264 | | 脱 | 脫 | 58,217 |
| 即 | 卽 | 128,551 | | 間 | 閒 | 56,993 |
| 清 | 淸 | 126,330 | | 増 | 增 | 46,315 |
| 徳 | 德 | 74,688 | | 内 | 內 | 40,412 |

全藏 4568 萬個可對照字中，兩藏相同 43,604,538、異體 1,837,140、大正藏獨有 388,270。正文差異約 4.8%，而其中**絕大多數是書寫層面的**，不是內容層面的。這個方向（大正藏偏日本通行字形、高麗藏偏傳統字形）是否符合刻本原貌，仍需以原書覆核——**數位文本的用字未必等於刻本用字**。

**分卷問題**：大正藏有 **181 卷**的卷範圍內已出現下一卷的卷題，即其分卷界線與刻本不符。例如 T2040 卷 1 的範圍涵蓋頁 0001–0052，而 0018c06 已出現「釋迦譜卷第二」。這會使卷界附近的位置對照偏移。高麗藏此類問題僅 1 卷。

**缺漏**：高麗藏缺第 42、43 冊；高麗藏 617 個缺頁（分佈 17 冊，第 45 冊即佔 333 頁）；大正藏 80 個缺頁。

2. 位置對照若出錯，在什麼情況下最致命？我猜想是卷界、品次轉折、序文與正文交界——但是否如此？
3. 底本與校本該如何表述才合本領域慣例？尤其高麗藏那一側的冊次與卷次對應關係。
