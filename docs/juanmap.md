# 高麗藏與大正藏分卷對照

## 術語
 goryeo 高麗大藏經，簡稱高麗藏，代號為 K，sqlite 數據庫是 K.db
 taisho 大正新修大藏經，簡稱大正藏，代號為 T，sqlite 數據庫是 T.db

大正藏原則上包括了所有高麗藏的經，其內容一致，但分行、分頁、標點、標記有出入。

## 文件
fileformat.md 文件位置格式
sqlaccess.md 定義 sqlite 讀取經卷的 API
packdb.ts 生成 數據庫的代碼
goryeo2taisho.json 高麗藏經號與大正藏經號對照表
taisho2goryeo.json 大正藏經號與高麗藏經號對照表

特別注意的是 經號、冊號、卷號 和pcl（頁行碼）的觀念，之後提到經文的「位置」就是使用它們來決定。

## 技術環境
Windows 11 64 位元。沒有c++編輯器。
有 bun , wails3 , git 以及 vs code 。

## 任務
生成的代碼直接寫到工作區。

1. 對每一部高麗藏的經，檢查相應的大正藏的經的卷數是否一致。撰寫 checkjuan.ts，輸出卷數不一的經典。
2. 對每一部高麗經的經，卷數又與大正藏相同。分別從 K.db , T.db 讀出每一卷的經文，進行比對。

### 相似度的算法

兩個版本的經卷，以 diff 比較，設計一個你覺得最有效能反應相似度的算法，考慮以下約束條件。
1. 開頭如果有一大段新增或缺少的文字，多半為序文，之後才是該卷的正文，最後可能有附文。必須輸出 正文 的起點，這是juaninfo 中沒有的信息。
2. 標點、標記（非漢字的ascii及數字組合），不計為差異。
3. diff 的比對結果，如果是替代關係（其他兩種是新增和刪除），如「峰」「峯」，也不計為差異。

撰寫一comparejuan.ts 的程序，由於運行時間可能較長，在運行時途中，不斷地將結果 append 到 comparejuan.tsv ，以利檢查。

comparejuan.tsv 的內容包括，也可以加你認為有用的。序言及附文整數表示，帶正號的整數表示高麗藏沒有，大正藏有的字數。帶負號則表示高麗經有，而被大正藏刪除的，+0 和 -0 就不必顯示了。

comparejuan.tsv 欄位：高麗經號、大正經號、卷數、漢字數、相似度、正文字數、序言字數、附文字數。
